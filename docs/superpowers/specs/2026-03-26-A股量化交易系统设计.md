# A股量化交易系统 - 设计规范

## 1. 系统概述

- **项目名称**：A股量化交易系统
- **项目类型**：事件驱动微服务架构
- **核心功能**：行情数据、选股策略、回测、实盘交易、持仓管理、风控
- **目标用户**：个人投资者

## 2. 技术栈

| 层级 | 技术选型 |
|------|----------|
| 后端 | Python 3.10+ / FastAPI / SQLAlchemy |
| 消息队列 | Redis |
| 数据库 | MySQL + Redis |
| 前端 | Vue3 + Element Plus + ECharts |
| 部署 | Docker + docker-compose |
| 数据源 | Tushare免费接口 |

## 4. 微服务清单

| 服务名 | 功能 | 端口 |
|--------|------|------|
| api-gateway | 统一API入口、认证、负载均衡 | 80 |
| strategy-engine | 策略编写、信号生成 | 8001 |
| backtest-service | 历史回测、绩效分析 | 8002 |
| trading-service | 模拟/实盘交易执行 | 8003 |
| portfolio-service | 持仓管理、资金管理 | 8004 |
| risk-service | 仓位风控、止损风控 | 8005 |
| data-service | 行情数据采集、存储 | 8006 |
| web-frontend | 前端界面 | 3000 |

## 5. 核心功能

### 5.1 数据服务
- 实时行情订阅（Tushare）
- 历史K线数据存储
- 财务数据同步

### 5.2 策略服务
- 策略编写（Python代码）
- 技术指标支持：MA、MACD、RSI、KDJ、布林带等
- 因子选股支持：PE、PB、ROE等
- 网格/趋势策略

### 5.3 回测服务
- 历史数据回测
- 绩效分析（收益率、夏普比率、最大回撤）
- 回测报告生成

### 5.4 交易服务
- 模拟交易
- 实盘交易（对接券商API或雪球模拟）
- 订单管理

### 5.5 持仓服务
- 持仓记录
- 资金流水
- 账户汇总

### 5.6 风控服务
- 交易前风控检查
- 持仓实时监控
- 止损止盈

## 6. 数据流设计

1. **实时行情**：数据服务 → MQ → 策略引擎 → 信号 → MQ → 交易服务
2. **回测**：前端 → 回测服务 → 数据服务 → 结果 → 前端
3. **风控**：交易前风控检查 + 持仓实时监控

## 7. 部署设计

使用 docker-compose 编排所有服务，详见 `docker-compose.yml`。
